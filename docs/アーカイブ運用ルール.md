# アーカイブ運用ルール

## 1. 目的

本書は、sessionSet アーカイブの保持期限、削除、監査ログ、定期運用の扱いを定義するものです。

## 2. 保持ルール

- アーカイブはセッション実施日から 3 年間保持する
- retentionUntil は eventDate を基準に算出する
- 通常の一覧 API は deletedAt が null のデータのみ返す

## 3. 手動削除ルール

- 管理者は任意のタイミングでアーカイブを削除できる
- 削除時は即時に deletedAt を設定し、画面一覧から除外する
- 削除操作ごとに AdminAuditLog を 1 件作成する
- 監査ログには以下を保存する
  - action: archive_deleted
  - targetType: SessionArchive
  - targetId: archiveId
  - performedById
  - performedAt
  - summary
  - payload

## 4. 保持期限切れルール

- 日次バッチを毎日 03:10 に実行する
- retentionUntil を過ぎたアーカイブを検出する
- deletedAt が未設定なら deletedAt を付与する
- 同時に AdminAuditLog に archive_retention_expired を記録する

## 5. 物理削除ルール

- deletedAt から 30 日を経過したアーカイブは物理削除対象とする
- 物理削除前に対象件数を管理者向けに通知できる設計とする
- 物理削除後も AdminAuditLog は保持する

## 6. 復旧方針

- deletedAt 設定から 30 日以内は DB バックアップからの復旧余地を持つ
- アプリケーション上の通常機能としては復元 API を設けない

## 7. 実装上の注意

- レイティング集計はアーカイブ保存時に SessionArchiveRatingSummary へ固定化する
- 監査ログの payload には削除対象の要約情報を保存する
- 管理画面では手動削除と保持期限切れ削除を区別して表示する
