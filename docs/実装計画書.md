# Adolib-go KICK-OFF 実装計画書

## 1. 文書概要

本書は、Adolib-go KICK-OFF を段階的に実装するための計画書です。

前提:

- 現在は sessionSet 生成アプリが稼働している
- 既存の Next.js + Prisma + PostgreSQL を継続利用する

## 2. 実装方針

- 既存機能を壊さずに段階的に拡張する
- 認証とデータモデル拡張を先に行う
- 管理者機能とメンバー機能を早期に分離する
- sessionSet 生成機能は既存ロジックを中核として温存する

## 4. 開発優先順位

優先順位高:

1. 認証
2. メンバープロフィール
3. SessionEvent / SessionEntry
4. 管理者ダッシュボード
5. sessionSet 生成統合

優先順位中:

1. メール通知
2. お知らせ
3. 公開ページ

優先順位後:

1. チャット高度化
2. PDF 出力強化
3. コラム運用強化

## 5. リスクと対策

### 5.1 認証導入時の既存構成への影響

- 対策
  - 既存 API を段階的に保護対象へ移行する

### 5.2 sessionSet ロジックとイベント単位データの整合

- 対策
  - 既存 Participant / Request ベースから Event ベースへの変換層を設ける

### 5.3 メール送信コストと運用負荷

- 対策
  - MailLog と再送制御を設ける

### 5.4 チャット機能の実装コスト増大

- 対策
  - 初期は静的、同期型の簡易実装に限定する
